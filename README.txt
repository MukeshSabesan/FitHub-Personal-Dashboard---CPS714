This is our sub-project 2 (Member Dashboard and Profile Management).
In order to run this, the following needs to be done.

In the repository directory, install the following packages:
npm install react (not sure if it is necessary)
npm install firebase
npm install node

Then run this command:
npm run dev

This will return a localhost link, which can be run on your computer's web browser. In order to log in, you would need to be an authorized user.
